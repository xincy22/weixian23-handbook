## 行业选择建议

| 考虑因素 | 说明 |
| --- | --- |
| 个人兴趣 | 喜欢做什么比行业热度更重要 |
| 专业匹配 | 优先选择和专业背景相关的行业 |
| 发展前景 | 关注行业增长趋势，但不要只追热点 |
| 工作内容 | 同一行业内不同岗位差异很大，了解具体做什么 |
| 地域分布 | 芯片集中在上海/深圳/北京，互联网集中在北京/杭州/深圳 |
| 薪资水平 | 互联网和芯片设计薪资较高，但工作强度也大 |
| 读研 vs 就业 | 部分方向（如芯片设计、AI 算法）硕士起步，本科可以先实习了解 |
