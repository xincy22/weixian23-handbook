## 一、简历基本原则

| 原则 | 说明 |
| --- | --- |
| 一页 | 本科/硕士简历控制在一页 A4 |
| 量化 | 用数字说明成果（提升了 X%、处理了 Y 条数据、获得 Z 名次） |
| 相关性 | 根据目标岗位调整简历内容，突出相关经历 |
| 简洁 | 不写无关信息（高中经历、无关社团） |
| 真实 | 写的每一条都要能在面试中展开讲 |

## 二、简历结构建议

```
1. 基本信息
   姓名、电话、邮箱、GitHub（如有）、学校、专业、年级

2. 教育背景
   学校、专业、GPA（如果不错的话）、相关课程

3. 项目经历（最重要）
   每个项目写：
   - 项目名称 + 时间
   - 项目背景（一句话）
   - 你做了什么（具体技术和工作）
   - 成果（量化）

4. 实习经历（如有）
   公司、岗位、时间、具体工作和成果

5. 技能
   编程语言、工具、框架（写熟练程度）

6. 获奖 / 其他（如有）
   竞赛、奖学金、论文、开源贡献
```

## 三、项目经历怎么写

### STAR 法则

| 要素 | 说明 | 示例 |
| --- | --- | --- |
| Situation | 项目背景 | 「课程项目要求实现一个 XX 系统」 |
| Task | 你的任务 | 「我负责后端 API 设计和数据库优化」 |
| Action | 你做了什么 | 「使用 Python + FastAPI 实现了 RESTful API，设计了数据库索引」 |
| Result | 成果 | 「接口响应时间从 2s 降低到 200ms，支持 1000 并发」 |

### 示例

```
基于深度学习的医学图像分割系统（2025.03 - 2025.06）
- 使用 PyTorch 实现 U-Net 模型，对肺部 CT 图像进行病灶分割
- 在公开数据集上达到 Dice 系数 0.87，超过基线方法 5%
- 使用数据增强和学习率调度策略提升模型泛化能力
- 技术栈：Python, PyTorch, OpenCV, Linux
```

## 四、技能怎么写

不要只列名字，标注熟练程度：

```
编程语言：Python（熟练）、C++（熟悉）、Verilog（了解）
框架工具：PyTorch、scikit-learn、Git、Linux、Docker
专业工具：MATLAB、Cadence Virtuoso、Vivado（根据方向选）
```

## 五、面试类型

| 类型 | 内容 | 准备方式 |
| --- | --- | --- |
| 技术面（算法） | 手撕代码、数据结构、算法 | LeetCode 刷题 |
| 技术面（专业） | 专业知识、项目深挖 | 复习专业课、准备项目讲解 |
| 技术面（系统设计） | 设计一个系统的架构 | 学习系统设计基础（高年级/研究生） |
| 行为面 | 团队合作、冲突处理、自我认知 | 准备 3-5 个故事 |
| HR 面 | 职业规划、薪资期望、到岗时间 | 了解行业薪资水平 |

## 六、技术面试准备

### 互联网 / AI 方向

| 准备项 | 建议 |
| --- | --- |
| 数据结构 | 数组、链表、栈、队列、树、图、哈希表 |
| 算法 | 排序、二分、双指针、DFS/BFS、动态规划、贪心 |
| 刷题量 | 至少 100-150 道（Easy 30% + Medium 60% + Hard 10%） |
| 刷题平台 | LeetCode、牛客 |
| 项目 | 能讲清楚技术选型、难点、解决方案、成果 |

### 芯片方向

| 准备项 | 建议 |
| --- | --- |
| 数字基础 | 组合逻辑、时序逻辑、状态机、CDC |
| Verilog | 语法、可综合写法、常见电路实现 |
| 验证 | SystemVerilog、UVM 基础概念 |
| 后端 | 综合、STA、布局布线基本概念 |
| 模拟 | MOSFET、运放、带隙基准、PLL |

### 材料 / 生医 / 仪器方向

| 准备项 | 建议 |
| --- | --- |
| 专业基础 | 复习核心专业课知识点 |
| 实验技能 | 能讲清楚做过的实验和结果 |
| 工具使用 | 熟悉方向内常用软件和仪器 |
| 论文 | 能讲清楚读过的论文和自己的理解 |

## 七、行为面试准备

准备 3-5 个故事，覆盖以下主题：

| 主题 | 示例问题 |
| --- | --- |
| 团队合作 | 「讲一个你和团队合作完成的项目」 |
| 解决困难 | 「遇到过最大的技术挑战是什么」 |
| 失败经历 | 「讲一个你失败的经历，你学到了什么」 |
| 主动性 | 「你主动做过什么超出要求的事」 |
| 时间管理 | 「多个任务同时进行时你怎么安排」 |

---

## 八、面试通用建议

```
1. 面试前：研究公司和岗位，准备针对性问题
2. 自我介绍：1-2 分钟，突出和岗位相关的经历
3. 项目讲解：先说整体，再说你的部分，最后说成果
4. 不会的题：说出你的思路，即使不完整也比沉默好
5. 反问环节：问团队做什么、技术栈、新人成长路径
6. 面试后：总结不足，下次改进
```
