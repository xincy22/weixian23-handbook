## 校内渠道

| 渠道 | 说明 | 获取方式 |
| --- | --- | --- |
| 学校就业信息网 | 校招、实习、宣讲会信息 | 学校官网就业板块 |
| 学院就业群 / 通知 | 学院转发的招聘信息 | 班群、学院公众号 |
| 导师推荐 | 实验室合作企业的实习机会 | 主动和导师沟通 |
| 校友内推 | 学长学姐在企业内部推荐 | 校友群、LinkedIn |
| 校园招聘会 | 秋招/春招现场 | 学校就业中心通知 |

## 线上招聘平台

| 平台 | 适合找什么 | 说明 |
| --- | --- | --- |
| 牛客网 | 互联网/芯片实习和校招 | 有面经、笔试题、内推信息 |
| BOSS 直聘 | 各行业实习和全职 | 可以直接和 HR 聊 |
| 实习僧 | 实习岗位 | 专注实习，信息量大 |
| 猎聘 | 中高端岗位 | 适合有经验后使用 |
| LinkedIn | 外企、国际化岗位 | 适合外企和海外机会 |
| 智联招聘 / 前程无忧 | 传统行业、国企 | 覆盖面广 |

## 实习时间线

| 时间 | 事项 |
| --- | --- |
| 大二暑假 | 可以开始找第一段实习（要求不高，重在体验） |
| 大三寒假 | 准备春招实习（互联网春招通常 2-4 月） |
| 大三暑假 | 暑期实习（最重要的一段，很多公司暑期实习转正） |
| 大四秋季 | 秋招（正式校招，8-11 月） |
| 大四春季 | 春招补录（秋招没拿到 offer 的补充机会） |

## 实习准备建议

| 准备项 | 说明 |
| --- | --- |
| 简历 | 参见 [简历与面试准备](./resume.mdx) |
| 项目经验 | 至少有 1-2 个能讲清楚的项目 |
| 基础知识 | 数据结构、专业课基础（根据岗位） |
| 编程能力 | LeetCode 刷题（互联网）/ 专业工具使用（芯片/材料） |
| 面试准备 | 技术面 + 行为面 + HR 面 |
| 信息收集 | 提前了解目标公司和岗位要求 |
