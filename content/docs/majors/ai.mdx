## 1. 这个方向主要研究什么？

人工智能（AI）和机器学习（ML）研究如何让计算机从数据中学习规律并做出决策。涵盖深度学习、计算机视觉、自然语言处理、强化学习、推荐系统、语音识别等。近年来大语言模型（LLM）、生成式 AI、多模态模型是最热门的方向。AI 已经渗透到几乎所有工程和科学领域。

## 8. 学习路线建议

```
入门阶段（1-2 个月）：
→ 学好 Python 和 numpy/pandas
→ 学习机器学习基础概念（监督/无监督/过拟合/交叉验证）
→ 用 scikit-learn 跑通几个经典算法
→ 学习线性代数和概率论（如果不熟）

进阶阶段（2-4 个月）：
→ 学习深度学习基础（MLP、CNN、RNN、Transformer）
→ 用 PyTorch 实现经典模型
→ 选择一个子方向深入（CV / NLP / RL / 多模态）
→ 做 1-2 个完整项目或 Kaggle 竞赛

项目/科研/实习阶段：
→ 阅读方向内的经典论文和最新论文
→ 复现论文结果
→ 进实验室参与课题或参加竞赛
→ 准备实习：刷算法题 + 项目经验 + 论文
```
