## 1. 这个方向主要研究什么？

集成电路（IC）方向研究如何在硅片上设计、制造和验证芯片。涵盖从电路设计、逻辑综合、物理版图到制造工艺的全流程。研究对象包括数字芯片（处理器、FPGA）、模拟芯片（ADC、PLL、电源管理）、射频芯片和存储器等。这个方向直接支撑消费电子、通信、汽车、AI 加速器等产业。

## 8. 学习路线建议

```
入门阶段（1-2 个月）：
→ 学好数字逻辑基础（组合逻辑、时序逻辑、状态机）
→ 学 Verilog HDL 语法，能写简单模块并仿真
→ 了解 FPGA 开发流程（Vivado）

进阶阶段（2-4 个月）：
→ 数字方向：学习 RTL 设计规范、时序约束、综合流程
→ 模拟方向：学习 MOSFET 器件模型、基本放大器、运放设计
→ 验证方向：学习 SystemVerilog、UVM 基础
→ 做一个完整的小项目（如简单 CPU 或通信模块）

项目/科研/实习阶段：
→ 进实验室参与实际芯片设计项目
→ 学习后端流程（综合、布局布线、时序收敛）
→ 准备实习：刷数字 IC 面试题、做项目积累
```
