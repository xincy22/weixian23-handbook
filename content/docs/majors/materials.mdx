## 1. 这个方向主要研究什么？

材料科学研究材料的组成、结构、性能和加工之间的关系，目标是开发满足特定需求的新材料或改进现有材料。涵盖金属、陶瓷、高分子、半导体、纳米材料、能源材料、生物材料等。近年来材料信息学（用 AI/计算方法加速材料研发）成为热门交叉方向。

## 8. 学习路线建议

```
入门阶段（1-2 个月）：
→ 学好材料科学基础（晶体结构、相图、缺陷、力学性能）
→ 了解主要材料类别和应用
→ 学习 Python 基础（为计算和数据分析做准备）

进阶阶段（2-4 个月）：
→ 选择子方向：实验 / 计算 / 材料信息学
→ 实验方向：学习表征方法（XRD、SEM、TEM）
→ 计算方向：学习 DFT 或分子动力学基础
→ 信息学方向：学习机器学习 + 材料数据库使用

项目/科研/实习阶段：
→ 进实验室参与课题
→ 计算方向可以用公开数据库做项目
→ 关注材料信息学竞赛和开源项目
```
