## 1. 这个方向主要研究什么？

生物医学工程是工程技术与医学/生物学的交叉学科。研究如何用工程方法解决医学和健康问题，包括医疗器械开发、医学影像处理、生物信号分析、生物材料、神经工程、康复工程等。这个方向的产出直接服务于临床诊断、治疗和健康监测。

## 8. 学习路线建议

```
入门阶段（1-2 个月）：
→ 了解生物医学工程的主要分支
→ 学好 Python 和基础信号/图像处理
→ 了解常见生理信号（ECG、EEG）和医学影像（CT、MRI）

进阶阶段（2-4 个月）：
→ 选择一个子方向深入（医学影像 / 生物信号 / 神经工程）
→ 学习相关的机器学习/深度学习方法
→ 用公开数据集做一个完整项目

项目/科研/实习阶段：
→ 进实验室参与课题
→ 参加医学影像相关竞赛（Grand Challenge、Kaggle）
→ 了解医疗器械行业和法规（如果考虑就业）
```
