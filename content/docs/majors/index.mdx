## 模板结构（统一）

每个方向页面建议包含：

1. 这个方向主要研究什么
2. 入门关键词（中英对照）
3. 推荐课程 / 公开课
4. 推荐书籍
5. 常用工具 / 软件 / 数据库
6. 适合做的小项目
7. 实验室 / 课题组 / 企业方向
8. 学习路线建议（入门 → 进阶 → 项目/科研/实习）
