## 本目录内容

- [生物医学工程](./biomedical.mdx) — 医学影像、医疗器械、生信、可穿戴
- [精密仪器与测控](./instrument.mdx) — 传感器、精密测量、惯导、机器人

## 模板结构（统一）

每个方向页面建议包含：

1. 这个方向主要研究什么
2. 入门关键词（中英对照）
3. 推荐课程 / 公开课
4. 推荐书籍
5. 常用工具 / 软件 / 数据库
6. 适合做的小项目
7. 实验室 / 课题组 / 企业方向
8. 学习路线建议（入门 → 进阶 → 项目/科研/实习）

> 给贡献者：新建方向页时可复制 [`_template.mdx`](https://github.com/xincy22/weixian23-handbook/blob/main/content/docs/majors/_template.mdx) 作为骨架。该文件不在侧边栏展示。
