## 1. 这个方向主要研究什么？

计算机科学与软件开发涵盖从底层系统（操作系统、编译器、计算机网络）到上层应用（Web 开发、移动端、分布式系统、数据库）的全栈技术。对于非计算机专业的工科学生来说，编程能力和软件工程素养是科研、项目开发和就业的通用基础能力。

## 8. 学习路线建议

```
入门阶段（1-2 个月）：
→ 学好一门语言（Python 或 C++）
→ 学习数据结构基础（数组、链表、栈、队列、树、图）
→ 学会使用 Git 和命令行
→ 完成 CS50 或类似入门课

进阶阶段（2-4 个月）：
→ 学习算法（排序、搜索、动态规划、图算法）
→ 了解操作系统和计算机网络基础
→ 选择一个应用方向（Web / 系统 / 嵌入式）
→ 做 1-2 个完整项目

项目/科研/实习阶段：
→ 刷 LeetCode（实习面试必备）
→ 做有一定复杂度的项目（全栈应用 / 开源贡献）
→ 学习系统设计（如果目标是大厂后端）
→ 准备简历和面试
```

## 9. 对非计算机专业同学的建议

如果你不是计算机专业，但需要编程能力：

| 你的需求 | 建议学什么 |
| --- | --- |
| 科研数据处理 | Python + numpy/pandas + matplotlib |
| AI/ML 方向 | Python + PyTorch + Linux |
| 嵌入式/硬件 | C 语言 + Linux + Git |
| 自动化脚本 | Python + Shell |
| 课程项目 | 看项目要求选语言 |
| 找互联网实习 | 数据结构 + 算法 + 一个方向的项目经验 |

不需要把所有东西都学完。根据你的目标选择最相关的技能栈，深入到能做项目的程度即可。
