## 一、核心原则

**AI 可以帮你写得更好，但不能替你写。**

最终提交的内容必须是你理解、认可并能为之负责的。如果被问到「这段话什么意思」「为什么这样写」，你必须能回答。

---

## 二、AI 在写作中能做什么

| 用法 | 说明 | 推荐 Prompt |
| --- | --- | --- |
| **润色表达** | 改善语言质量，不改变内容 | "帮我润色这段英文，保持学术风格，不要改变原意" |
| **修正语法** | 纠正语法和拼写错误 | "检查这段文字的语法问题，列出修改点" |
| **梳理大纲** | 帮你组织文章结构 | "我要写关于 X 的报告，帮我列个大纲" |
| **检查逻辑** | 发现论述中的逻辑漏洞 | "这段论证有没有逻辑跳跃或自相矛盾" |
| **翻译辅助** | 中英互译，保持学术风格 | "把这段翻译成学术英文，标注不确定的术语" |
| **总结已有材料** | 帮你整理已有内容 | "帮我把这三段话合并成一段摘要" |
| **格式转换** | 调整格式 | "把这个列表转成三线表格式" |
| **生成示例** | 给你参考写法 | "给我一个 Introduction 段落的写法示例" |
| **同义词替换** | 避免重复用词 | "这段话中 'important' 出现了 4 次，帮我替换" |
| **缩写扩写** | 调整篇幅 | "这段 500 字太长，帮我精简到 300 字，保留核心信息" |

---

## 三、AI 在写作中不应该做什么

| 禁止用法 | 为什么不行 | 后果 |
| --- | --- | --- |
| 让 AI 直接代写整篇报告 | 不是你的理解和表达 | AIGC 检测标记 + 学术不端 |
| 让 AI 编造实验结果 | AI 会生成看似合理但虚假的数据 | 学术造假（最严重的学术不端） |
| 让 AI 编造参考文献 | AI 经常生成不存在的论文 | 引用虚假文献 |
| 直接提交 AI 输出不做修改 | 可能有事实错误、逻辑问题、风格不一致 | 质量无法保证 + AIGC 检测 |
| 用 AI 改写他人内容绕过查重 | 本质仍是抄袭 | 学术不端 |
| 让 AI 写同行评审意见 | 违反审稿伦理 | 学术不端 |

## 四、正确的 AI 辅助写作流程

### 标准流程

```
1. 自己先写初稿
   → 哪怕很粗糙、有语法错误都没关系
   → 关键是内容和逻辑是你自己的

2. 用 AI 润色语言
   → 一段一段润色，不要一次性丢整篇
   → Prompt："帮我润色这段，保持学术风格，不要改变原意"

3. 对照修改，理解为什么这样改
   → 不要盲目接受所有修改
   → 理解 AI 为什么这样改，学习表达方式

4. 接受合理修改，拒绝改变原意的修改
   → AI 有时会「过度润色」，加入你没说的内容
   → 发现这种情况要回退

5. 自己做最终判断和定稿
   → 最终版本必须是你认可的

6. 核验事实性内容
   → 数据、引用、具体数字必须自己确认

7. 如需声明，添加 AI 使用声明
```

### 错误流程（不要这样做）

```
× 拿到题目 → 让 AI 写全文 → 复制粘贴 → 提交
× 让 AI 写初稿 → 自己改几个词 → 提交
× 把别人的论文喂给 AI → "帮我改写" → 当成自己的
```

## 五、不同文档类型的 AI 使用程度

| 文档类型 | AI 可以做 | AI 不能做 | 是否需要声明 |
| --- | --- | --- | --- |
| **个人笔记** | 随意使用 | — | 不需要 |
| **课程报告** | 润色、语法检查、结构建议 | 代写内容 | 看课程政策 |
| **文献综述** | 翻译、总结单篇论文、格式整理 | 代写分析和观点 | 看课程/导师要求 |
| **毕业论文** | 语言润色、格式调整 | 代写任何实质内容 | 多数学校要求声明 |
| **期刊投稿** | 语言润色（English polishing） | 代写、生成数据/图像 | **必须声明** |
| **项目申报书** | 结构建议、表达优化 | 编造技术方案和创新点 | 视要求而定 |
| **大创/竞赛报告** | 润色、格式 | 代写核心内容 | 建议声明 |

## 六、AI 润色的实操技巧

### 分段润色（推荐）

```
不要：把整篇 5000 字论文一次性丢给 AI
要：一段一段润色，每次 200-500 字

原因：
- 短文本润色质量更高
- 你能逐段对照检查
- 避免 AI 改变整体逻辑
```

### 给 AI 明确约束

```
好的 Prompt：
"帮我润色这段学术英文。要求：
1. 保持原意不变
2. 保持学术正式风格
3. 不要增加原文没有的信息
4. 如果原文逻辑不清楚，指出问题而不是帮我编造逻辑
5. 列出主要修改点和原因"

差的 Prompt：
"帮我改一下这段话"
→ AI 可能大幅改写，加入你没说的内容
```

### 多轮迭代

```
第一轮：整体润色
第二轮："这里能不能更简洁"
第三轮："这个表达太口语了，换个学术表达"
第四轮："检查一下这段的逻辑连接词是否恰当"
```

### 保留修改记录

```
建议做法：
- Word：使用「修订」模式，保留修改痕迹
- LaTeX/Overleaf：用 Git 版本管理，每次润色后 commit
- 保留 AI 润色前后的对比，方便回溯
```

## 七、AI 使用声明模板

### 中文声明（课程报告/毕业论文）

```
声明：本文在写作过程中使用了 AI 工具（Claude / ChatGPT）辅助语言润色和
语法检查。所有研究内容、数据分析、实验结果和学术观点均为作者原创工作。
AI 工具未参与研究设计、数据收集、实验执行或结论推导。
```

### 英文声明（期刊投稿）

```
Disclosure of AI Usage:
During the preparation of this manuscript, [Tool Name] ([Version], [Developer])
was used for language polishing and grammar checking of the manuscript text.
The authors reviewed and edited all AI-assisted content and take full
responsibility for the accuracy and integrity of the final manuscript.
The AI tool was not used for data analysis, experimental design, or
generation of scientific content.
```

### 声明四要素

无论中英文，确保包含：
```
□ 工具名称和版本（如 "Claude Sonnet 4.6, Anthropic"）
□ 具体用途（语言润色、语法检查等）
□ 明确排除项（未用于数据分析、实验设计等）
□ 责任声明（作者对所有内容负全责）
```

## 八、常见问题

| 问题 | 回答 |
| --- | --- |
| 用 Grammarly 算不算用 AI？ | 严格来说算。如果课程/期刊要求声明，建议声明 |
| 用 AI 翻译后自己修改，算代写吗？ | 如果你理解并修改了内容，通常不算。但建议声明 |
| AI 润色后 AIGC 检测会标记吗？ | 可能会。润色程度越大，被标记概率越高 |
| 怎么降低 AIGC 检测率？ | 最好的方法是自己写初稿，只让 AI 做轻度润色 |
| 导师让我用 AI 润色，但学校查 AI 率怎么办？ | 和导师沟通，确认学校具体政策。轻度润色通常不会超标 |
| 用 AI 生成的大纲算不算代写？ | 大纲是结构建议，通常不算。但内容必须自己写 |

## 九、提交前检查清单

```
□ 所有内容我都理解并认可
□ 如果被问到任何一段，我能解释清楚
□ 没有 AI 编造的参考文献（已在数据库核实）
□ 没有 AI 编造的数据或实验结果
□ 事实性信息已经人工核验
□ 符合课程/期刊对 AI 使用的规定
□ 如需声明，已添加 AI 使用声明
□ AIGC 检测率在学校要求范围内（如适用）
□ 润色没有改变我的原意
□ 最终版本反映的是我自己的思考和理解
```
