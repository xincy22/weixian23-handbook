> Word 自带的公式编辑器支持 UnicodeMath 语法，可以像打字一样快速输入公式，不需要鼠标点击。
> 掌握这套语法后，在 Word 里写公式的速度可以接近 LaTeX。
> 最后更新：2026-05-20

---

## 一、基本操作

### 进入公式模式

| 操作 | 快捷键 |
| --- | --- |
| 插入公式 | `Alt` + `=` |
| 线性格式 → 专业格式（排版好的公式） | 选中公式后 `Ctrl` + `=` |
| 专业格式 → 线性格式 | 选中公式后 `Ctrl` + `Shift` + `=` |

### 核心规则

1. 按 `Alt` + `=` 进入公式编辑区
2. 输入 UnicodeMath 线性表达式
3. 按**空格**触发转换（`\alpha` → α）
4. 按**两次空格**完成完整排版（积分、求和的上下限）
5. 括号 `()` 用于分组

## 二、分数

| 输入 | 渲染结果 | 说明 |
| --- | --- | --- |
| `a/b` | $\frac{a}{b}$ | 最基本的分数 |
| `(a+b)/(c+d)` | $\frac{a+b}{c+d}$ | 括号分组 |
| `1/(x^2+1)` | $\frac{1}{x^2+1}$ | 复杂分母 |
| `(x^2+2x+1)/(x+1)` | $\frac{x^2+2x+1}{x+1}$ | 多项式分数 |

**关键**：没有括号时，`/` 只把紧邻的单个字符作为分子/分母。多字符必须加括号。

```
错误：a+b/c+d   → a + (b/c) + d，只有 b 和 c 构成分数
正确：(a+b)/(c+d) → 整个 a+b 在分子，c+d 在分母
```

## 五、括号与分隔符（\open / \close）

### 自动缩放括号

在 Word 公式中，直接输入的括号 `(` `)` `[` `]` `{` `}` 会**自动缩放**以匹配内容高度。这是 UnicodeMath 相比 LaTeX 的一个便利之处——不需要写 `\left` `\right`。

| 输入 | 渲染结果 | 说明 |
| --- | --- | --- |
| `(a/b)` | $\left(\frac{a}{b}\right)$ | 圆括号自动缩放 |
| `[a/b]` | $\left[\frac{a}{b}\right]$ | 方括号自动缩放 |
| `{a/b}` | $\left\{\frac{a}{b}\right\}$ | 花括号自动缩放 |

### \open 和 \close（显式控制）

当你需要**不匹配的括号**或**特殊分隔符**时，使用 `\open` 和 `\close`：

| 输入 | 渲染结果 | 说明 |
| --- | --- | --- |
| `\open(a/b\close]` | $\left(\frac{a}{b}\right]$ | 左圆括号 + 右方括号（半开区间） |
| `\open[a,b\close)` | $\left[a,b\right)$ | 左闭右开区间 |
| `\open\|x\close\|` | $\left\|x\right\|$ | 范数（双竖线） |
| `\open(x\close.` | $\left(x\right.$ | 只有左括号（右侧不可见） |
| `\open.x\close)` | $\left.x\right)$ | 只有右括号（左侧不可见） |

**语法**：`\open` + 左分隔符 + 内容 + `\close` + 右分隔符。用 `.` 表示不可见的一侧。

### 特殊括号类型

| 输入 | 渲染结果 | 名称 | 用途 |
| --- | --- | --- | --- |
| `\lfloor` ... `\rfloor` | $\lfloor x \rfloor$ | 下取整 | 取整函数 |
| `\lceil` ... `\rceil` | $\lceil x \rceil$ | 上取整 | 取整函数 |
| `\langle` ... `\rangle` | $\langle x \rangle$ | 尖括号 | 内积、期望值 |
| `\|` ... `\|` | $\| x \|$ | 双竖线 | 范数 |
| `|` ... `|` | $|x|$ | 单竖线 | 绝对值 |

### 括号内分隔符（\vbar）

`\vbar` 在括号内插入竖线分隔符（常用于条件概率、集合定义）：

| 输入 | 渲染结果 | 用途 |
| --- | --- | --- |
| `{x\vbar x>0}` | $\{x \mid x>0\}$ | 集合定义 |
| `(a/b\vbar x+y\vbar z)` | 带两个分隔符的表达式 | 多段分隔 |
| `P(A\vbar B)` | $P(A \mid B)$ | 条件概率 |

### 矩阵专用括号

| 输入 | 渲染结果 | 说明 |
| --- | --- | --- |
| `\pmatrix(a&b@c&d)` | $\begin{pmatrix}a&b\\c&d\end{pmatrix}$ | 圆括号矩阵 |
| `\bmatrix(a&b@c&d)` | $\begin{bmatrix}a&b\\c&d\end{bmatrix}$ | 方括号矩阵 |
| `\Bmatrix(a&b@c&d)` | $\begin{Bmatrix}a&b\\c&d\end{Bmatrix}$ | 花括号矩阵 |
| `\vmatrix(a&b@c&d)` | $\begin{vmatrix}a&b\\c&d\end{vmatrix}$ | 行列式（单竖线） |
| `\Vmatrix(a&b@c&d)` | $\begin{Vmatrix}a&b\\c&d\end{Vmatrix}$ | 范数矩阵（双竖线） |

## 十、函数应用（\funcapply）

### 背景

Word 公式编辑器有一套**数学自动更正**（Math AutoCorrect）内置函数列表。当你在公式区域输入这些函数名时，Word 会自动将其识别为函数（正体显示、后面的内容作为参数处理）：

```
sin  cos  tan  cot  sec  csc
arcsin  arccos  arctan
sinh  cosh  tanh  coth
log  ln  lg  exp
lim  limsup  liminf
max  min  sup  inf
det  dim  ker  deg
gcd  lcm  arg  mod
Pr  hom
```

这些函数你直接打名字 + 空格就行，Word 自动处理。

### 问题：自动更正列表之外的函数

当你使用**不在上述列表中的函数名**时（比如 `tr`、`sgn`、`Var`、`softmax`），Word 不会自动识别它是函数，而是把每个字母当作独立变量，显示为斜体：$t \cdot r$ 而不是 $\operatorname{tr}$。

### 解决：\funcapply

`\funcapply`（Unicode U+2061，不可见的"函数应用"运算符）的作用是告诉 Word：**左边是函数名（应显示为正体），右边是它的参数**。

它只在 Word 数学自动更正没有覆盖到的函数中才需要使用。

### 用法

| 输入 | 渲染结果 | 场景 |
| --- | --- | --- |
| `sgn\funcapply(x)` | $\operatorname{sgn}(x)$ | 符号函数 |
| `tr\funcapply A` | $\operatorname{tr} A$ | 矩阵的迹 |
| `diag\funcapply(a,b,c)` | $\operatorname{diag}(a,b,c)$ | 对角矩阵 |
| `Var\funcapply(X)` | $\operatorname{Var}(X)$ | 方差 |
| `Cov\funcapply(X,Y)` | $\operatorname{Cov}(X,Y)$ | 协方差 |
| `softmax\funcapply(z)` | $\operatorname{softmax}(z)$ | 机器学习激活函数 |
| `ReLU\funcapply(x)` | $\operatorname{ReLU}(x)$ | 激活函数 |
| `rank\funcapply A` | $\operatorname{rank} A$ | 矩阵的秩 |
| `span\funcapply(v_1,v_2)` | $\operatorname{span}(v_1,v_2)$ | 张成空间 |
| `supp\funcapply f` | $\operatorname{supp} f$ | 支撑集 |

### 带上下限的自定义函数

```
argmin_(x\in S)\funcapply f(x)
```

$$\operatorname*{argmin}_{x\in S} f(x)$$

```
argmax_\theta\funcapply L(\theta)
```

$$\operatorname*{argmax}_{\theta} L(\theta)$$

### 总结

```
内置函数（sin、cos、log、lim 等）→ 直接打，Word 自动识别
自定义函数（tr、Var、softmax 等）→ 函数名 + \funcapply + 参数
```

`\funcapply` 本身是不可见字符，不会出现在最终排版中，它只是一个语义标记。

## 十一、矩阵

语法：`\matrix(行1列1&行1列2@行2列1&行2列2)` — `&` 分隔列，`@` 分隔行。

| 输入 | 渲染结果 |
| --- | --- |
| `(\matrix(a&b@c&d))` | $\begin{pmatrix}a&b\\c&d\end{pmatrix}$ |

```
(\matrix(a_(11)&\cdots&a_(1n)@\vdots&\ddots&\vdots@a_(m1)&\cdots&a_(mn)))
```
$$\begin{pmatrix}a_{11}&\cdots&a_{1n}\\\vdots&\ddots&\vdots\\a_{m1}&\cdots&a_{mn}\end{pmatrix}$$

## 十二、方程组和多行对齐

### 方程组

输入 `\eqarray(x+y&=1@x-y&=3)` 得到：

$$\begin{aligned}x+y&=1\\x-y&=3\end{aligned}$$

`@` 分隔行，`&` 是对齐点。

### 分段函数

输入 `f(x)={\eqarray(x^2,  &x\geq 0@-x^2,  &x<0)` 得到：

$$f(x)=\begin{cases}x^2, & x\geq 0\\-x^2, & x&lt;0\end{cases}$$

## 十三、公式编号

> 公式编号不是 UnicodeMath 语法的一部分，而是 Word 文档排版和引用管理的一部分。
> 如果文档里会增删公式，不要只靠手打编号；至少要用交叉引用，最好让编号本身也自动生成。

### 先选方法

| 需求 | 推荐方法 | 适合场景 |
| --- | --- | --- |
| 公式编号要和公式同一行并靠右 | UnicodeMath 的 `#(...)` | Word 2016+、论文/报告常用版式 |
| 编号里有连字符或文字 | 在编号里用双引号，如 `#("1-1")` | 避免 `1-1` 被当成数学减法 |
| 公式顺序会频繁变化 | `#(...)` + `SEQ` 字段 + 书签 | 自动编号、自动引用 |
| 需要 Word 原生题注和公式目录 | 题注（Caption）+ 交叉引用 | 学校模板要求题注、需要生成公式目录 |

### 手动编号：公式里直接用 `#(...)`

Word 的 UnicodeMath 支持在公式内部写编号。做法是在公式末尾输入 `#`，后面接要显示在右侧的编号：

```
E=mc^2#(1)
```

如果编号是章节号形式，尤其是 `1-1` 这种带连字符的格式，建议把编号内容放进英文双引号：

```
E=mc^2#("1-1")
```

原因是公式区域里的 `-` 默认会按数学减号处理。`"1-1"` 表示普通文本，可以避免连字符被渲染成减号，也能保持编号更像正文文本。

基本流程：

1. 按 `Alt` + `=` 进入公式区域
2. 输入公式正文
3. 在公式末尾输入 `#("1-1")` 或 `#(1)`
4. 按空格或回车转换为专业格式

这种方式会把编号作为公式结构的一部分放到右侧，比“公式外面再放一个文本编号”更符合 Word 公式编辑器的设计。

**注意**：`#(...)` 只负责把编号排到公式右侧；如果编号内容是手动输入的，删除或插入公式后，后面的编号不会自动变化。至少要先给每个编号加书签，再在正文引用处使用“交叉引用”，不要在正文里手打“见公式 (1-1)”。

### 自动编号：把 SEQ 字段放进 `#(...)`

如果想保留 `#(...)` 的右侧编号版式，同时让编号自动递增，可以用 `SEQ` 字段生成编号，再把这个字段放进 `#(...)` 的编号位置。

基本做法：

1. 先输入公式和编号结构，例如 `E=mc^2#()`
2. 把光标放到 `#()` 的括号中间
3. 按 `Ctrl` + `F9` 插入字段大括号
4. 在字段大括号里输入 `SEQ Eq`，形成 `{ SEQ Eq }`
5. 选中字段，按 `F9` 更新，显示为数字

字段代码看起来像这样：

```
E=mc^2#({ SEQ Eq })
```

这里的 `Eq` 是序列名，可以换成 `Equation`，但全文必须统一。下一处公式继续插入同样的 `{ SEQ Eq }`，更新后会显示为下一个编号。

如果要显示成章节式编号，如 `1-1`、`1-2`，可以把章节号作为普通文本放在字段前面，并把连字符也放在文本区域中；实际操作时要确认最终显示不是数学减号。手动章节号示例：

```
E=mc^2#("1-"{ SEQ Eq })
```

更复杂的章节号自动联动通常需要 `STYLEREF` 或题注的章节编号功能，设置成本更高；如果学校模板已经规定了编号规则，优先按模板来。

如果在公式区域里按 `Ctrl` + `F9` 不好用，可以先在正文或题注里生成 `SEQ` 编号字段，再把字段复制到 `#(...)` 的括号中间。不同 Word 版本对“公式区内编辑字段”的支持不完全一致，但最终目标都是让 `#(...)` 里放入会更新的编号内容。

### 自动引用：书签 + 交叉引用

`SEQ` 字段负责生成编号；正文里的“见公式 (1)”要用交叉引用，不要手打。

推荐流程：

1. 选中整个编号，包括括号，例如 `(1)`
2. `插入` → `书签`，给它起一个有意义的名字，如 `eq_energy`
3. 在正文需要引用的地方，选择 `引用` → `交叉引用`
4. 引用类型选择“书签”，引用内容选择“书签文字”
5. 选择对应书签，插入引用

这样正文里的编号会跟随书签文字更新。为了避免误删书签，编号附近不要随意剪切粘贴；移动公式时，最好整体移动公式、编号和书签所在内容。

### 题注：Word 原生自动编号

Word 也有官方的题注编号方式：选中公式后，进入 `引用` → `插入题注`，标签选择 `Equation` 或新建“公式”标签。之后正文可以通过 `引用` → `交叉引用` 引用对应题注。

题注的优点是原生、稳定，也方便生成公式目录。但它通常更适合把题注放在对象上方或下方；如果你想要“公式在中间、编号在同一行最右侧”的版式，优先用 UnicodeMath 的 `#(...)`，必要时再把题注/`SEQ` 生成的编号复制或放入 `#(...)` 的编号位置。

如果需要 `(1.1)` 这种带章节号的编号，题注可以在“编号...”里加入章节号；前提是章节标题必须使用稳定的标题样式和多级列表。不要只手动把标题加粗放大，否则 Word 无法可靠识别章节层级。

### 更新和排错

| 问题 | 处理 |
| --- | --- |
| 删除或移动公式后编号没变 | 在正文中按 `Ctrl` + `A` 全选，再按 `F9` 更新字段 |
| 看到 `{ SEQ Eq }` 而不是数字 | 按 `Alt` + `F9` 切换字段代码显示 |
| `1-1` 里的连字符像减号 | 写成 `#("1-1")`，让编号按文本处理 |
| 交叉引用没有更新 | 全选全文后按 `F9`，导出 PDF 前一定检查一遍 |
| 编号没有靠右 | 确认编号写在同一个公式区域内，并使用 `#(...)` |
| 章节号不对 | 检查标题是否用了 Word 的标题样式和多级列表 |

**推荐工作流**：先用 `#("1-1")` 这类公式内编号保证版式正确；如果文档会频繁增删公式，再把编号内容替换成 `SEQ` 字段；正文引用一律用书签和交叉引用；最终导出前在正文中执行一次 `Ctrl` + `A`、`F9`，再人工检查编号顺序。

## 十四、实战示例

| 公式 | UnicodeMath 输入 |
| --- | --- |
| $x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$ | `x=(-b\pm\sqrt(b^2-4ac))/(2a)` |
| $\nabla\cdot\vec{E}=\frac{\rho}{\epsilon_0}$ | `\nabla\cdot E\vec =\rho/\epsilon_0` |
| $F(\omega)=\int_{-\infty}^{\infty}f(t)e^{-j\omega t}dt$ | `F(\omega)=\int_(-\infty)^\infty f(t)e^(-j\omega t)dt` |
| $\sum_{k=0}^{n}\binom{n}{k}x^k(1-x)^{n-k}=1$ | `\sum_(k=0)^n \matrix(n@k) x^k(1-x)^(n-k)=1` |
| $\frac{\partial f}{\partial x}=\lim_{\Delta x\to 0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$ | `(\partial f)/(\partial x)=lim_(\Delta x\rightarrow 0) (f(x+\Delta x)-f(x))/(\Delta x)` |
| $\left\|Ax\right\| \leq \left\|A\right\|\cdot\left\|x\right\|$ | `\open\|Ax\close\| \leq \open\|A\close\|\cdot\open\|x\close\|` |

## 十五、UnicodeMath vs LaTeX 对比

| 操作 | UnicodeMath | LaTeX | 渲染结果 |
| --- | --- | --- | --- |
| 分数 | `a/b` | `\frac{a}{b}` | $\frac{a}{b}$ |
| 上标 | `x^2` | `x^{2}` | $x^2$ |
| 下标 | `x_i` | `x_{i}` | $x_i$ |
| 根号 | `\sqrt(x)` | `\sqrt{x}` | $\sqrt{x}$ |
| n次根 | `\sqrt(n&x)` | `\sqrt[n]{x}` | $\sqrt[n]{x}$ |
| 求和 | `\sum_(i=1)^n` | `\sum_{i=1}^{n}` | $\sum_{i=1}^n$ |
| 积分 | `\int_0^\infty` | `\int_{0}^{\infty}` | $\int_0^\infty$ |
| 矩阵 | `\pmatrix(a&b@c&d)` | `\begin{pmatrix}...` | $\begin{pmatrix}a&b\\c&d\end{pmatrix}$ |
| 向量标记 | `x\vec` | `\vec{x}` | $\vec{x}$ |
| 自动括号 | `(a/b)` | `\left(\frac{a}{b}\right)` | $\left(\frac{a}{b}\right)$ |
| 半开区间 | `\open[a,b\close)` | `\left[a,b\right)` | $\left[a,b\right)$ |

**结论**：UnicodeMath 更简洁（少打花括号，括号自动缩放），在 Word 中输入更快。

## 十六、效率技巧

1. **不要用鼠标点公式面板** — `Alt`+`=` 进入后直接打字
2. **善用括号分组** — 多字符的分子/分母/上下标都要加 `()`
3. **记住两次空格** — 积分、求和等 n-ary 运算符需要两次空格完成排版
4. **切换输入模式** — 公式区域右键可切换 UnicodeMath / LaTeX 模式
5. **Math AutoCorrect** — 文件→选项→校对→自动更正→Math AutoCorrect，可在普通文本中也使用 `\alpha` 等

## 十七、常见问题

| 问题 | 解决 |
| --- | --- |
| 按空格没有转换 | 确认光标在公式区域内（`Alt`+`=` 进入） |
| 分数只有一个字符在分子 | 用括号分组：`(a+b)/(c+d)` |
| 积分上下限没有排版 | 需要按两次空格 |
| 想输入普通空格 | 按 `Ctrl`+`Shift`+空格 |
| 公式字体不对 | 公式区域默认 Cambria Math，不要手动改 |
| 想在公式中输入文本 | 用 `"text"` 双引号包裹 |
| 括号没有自动变大 | 确认括号在公式区域内，且包裹了完整表达式 |
