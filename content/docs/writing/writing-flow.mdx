## 一、通用写作流程

无论写什么类型的学术文档，核心流程都是：

```
明确要求 → 列大纲 → 收集材料 → 写初稿 → 插入图表引用 → 润色语言 → 检查格式 → 提交前核验
```

### 各步骤详解

| 步骤 | 做什么 | 常见错误 | 时间占比 |
| --- | --- | --- | --- |
| 1. 明确要求 | 确定文档类型、读者、字数、格式、截止日期 | 没看清要求就开始写 | 5% |
| 2. 列大纲 | 确定章节结构，每节写什么、写多少 | 不列大纲直接写，写到一半结构混乱 | 10% |
| 3. 收集材料 | 找文献、整理数据、准备图表素材 | 边写边找资料，效率低 | 20% |
| 4. 写初稿 | 先把内容写出来，不追求完美 | 一边写一边改，进度极慢 | 30% |
| 5. 图表引用 | 添加图、表、公式、参考文献 | 图表编号混乱、引用格式不统一 | 15% |
| 6. 润色语言 | 检查表达、修改语法、优化逻辑连接 | 跳过这步直接交 | 10% |
| 7. 格式检查 | 统一标题、字体、编号、页眉页脚 | 先调格式再写内容（顺序反了） | 5% |
| 8. 提交前核验 | 确认引用完整、图表有标注、满足所有要求 | 漏掉参考文献、图表没编号 | 5% |

**关键原则**：先写内容，后调格式。不要在初稿阶段纠结排版。

## 二、课程报告写作

### 流程

```
1. 阅读作业要求
   → 字数限制、格式要求、是否需要引用、截止日期
   → 是否允许使用 AI（确认课程政策）

2. 确定主题和角度
   → 不要太宽泛（"深度学习" → "深度学习在医学图像分割中的应用"）

3. 列大纲（3-5 个主要章节）
   → 引言 → 背景/相关工作 → 主体内容 → 总结
   → 每个章节列 2-3 个要点

4. 快速文献调研
   → 找 5-10 篇相关文献（不需要太多）
   → 重点看摘要和结论，了解领域概况

5. 写初稿
   → 先写最熟悉的部分（不必从头写到尾）
   → 初稿 60 分就够，后面再迭代

6. 补充图表和数据
   → 每个论点最好有图表支撑

7. 添加引用和参考文献
   → 用 Zotero 一键插入

8. 润色和格式检查
   → 可以用 AI 辅助润色（参见 Prompt 模板）
   → 确认格式符合要求
```

### 课程报告结构模板

```
1. 引言（10-15%）
   - 背景介绍
   - 本报告的目的和范围

2. 相关工作/文献回顾（20-30%）
   - 已有研究概述
   - 分类讨论

3. 主体内容（40-50%）
   - 方法描述 / 分析讨论 / 实验结果
   - 图表展示

4. 总结与展望（10-15%）
   - 主要发现
   - 局限性
   - 未来方向

5. 参考文献
```

## 三、文献综述写作

### 流程

```
1. 确定综述范围
   → 时间范围（如 2020-2026）
   → 领域范围（如 "柔性压力传感器在健康监测中的应用"）
   → 关键词列表

2. 系统检索文献
   → 参见 03-文献检索与论文阅读/
   → 目标：找到 30-50 篇相关论文

3. 筛选和分类
   → 精读 5-10 篇核心论文
   → 泛读其余，提取关键信息
   → 按主题/方法/时间分类

4. 建立分类框架
   → 这是综述最核心的工作
   → 好的综述 = 好的分类体系 + 清晰的对比分析

5. 写作
   → 引言：为什么写这个综述、覆盖范围
   → 分类讨论：按你的框架逐类展开
   → 对比分析：各方法的优缺点对比表
   → 总结与展望：当前不足、未来方向

6. 制作对比表格
   → 方法对比表（方法名、年份、数据集、性能指标）
   → 这是综述的核心价值之一

7. 检查引用完整性
   → 每个论述都要有引用支撑
   → 不能凭空断言
```

### 文献综述结构模板

```
1. 引言（Introduction）
   - 领域背景
   - 综述动机（为什么需要这篇综述）
   - 综述范围和方法（检索策略、筛选标准）
   - 文章结构概述

2. 背景知识（Background）
   - 基本概念定义
   - 关键技术原理

3. 分类讨论（Main Body）
   - 类别 A：方法描述 → 代表工作 → 优缺点
   - 类别 B：方法描述 → 代表工作 → 优缺点
   - 类别 C：...
   - 对比表格

4. 讨论（Discussion）
   - 各类方法的综合对比
   - 当前挑战和未解决问题
   - 研究趋势

5. 总结与展望（Conclusion and Future Directions）
   - 主要发现总结
   - 未来研究方向建议

6. 参考文献
```

## 四、毕业论文写作

### 时间规划（以本科毕设为例）

| 阶段 | 时间 | 任务 |
| --- | --- | --- |
| 选题 + 开题 | 第 1-2 月 | 确定方向、文献调研、写开题报告 |
| 实验/开发 | 第 3-5 月 | 核心工作：实验、编程、数据收集 |
| 论文写作 | 第 5-6 月 | 写初稿（边做边写效率更高） |
| 修改完善 | 第 6-7 月 | 导师反馈、修改、查重、格式调整 |
| 答辩准备 | 最后 1-2 周 | PPT、预答辩、正式答辩 |

### 毕业论文结构

```
封面
摘要（中文 + 英文）
目录
第一章 绪论
  1.1 研究背景
  1.2 研究现状（文献综述）
  1.3 研究目的和意义
  1.4 论文结构
第二章 相关理论/技术基础
第三章 方法/系统设计
第四章 实验/实现
第五章 结果与分析
第六章 总结与展望
参考文献
致谢
附录（如有）
```

### 关键建议

```
1. 尽早开始写
   → 不要等实验全部做完再写
   → 边做边写：做完一个实验就写对应章节

2. 先写方法和实验章节
   → 这是你最熟悉的部分
   → 绪论和总结最后写

3. 导师反馈要及时
   → 写完一章就给导师看，不要攒到最后
   → 早期反馈能避免方向性错误

4. 查重要提前
   → 不要等到最后一天才查重
   → 留出修改时间

5. 格式用模板
   → 学校通常有官方 Word/LaTeX 模板
   → 从模板开始写，不要自己调格式
```

## 五、图表规范

### 图片规范

| 规范 | 说明 |
| --- | --- |
| 编号 | 图 1、图 2... 或 Fig. 1、Fig. 2...（全文统一） |
| 标题位置 | **图片下方** |
| 分辨率 | 至少 300 DPI（投稿用；课程报告 150 DPI 够用） |
| 格式 | 矢量图优先（PDF/SVG/EPS）；位图用 PNG（不要用 JPG） |
| 正文引用 | 每张图在正文中必须被提到（如「如图 1 所示」） |
| 图注 | 要能独立看懂（不看正文也能理解图在说什么） |

### 表格规范

| 规范 | 说明 |
| --- | --- |
| 编号 | 表 1、表 2... 或 Table 1、Table 2... |
| 标题位置 | **表格上方** |
| 格式 | 学术论文用三线表（顶线、栏目线、底线，无竖线） |
| 单位 | 在表头标注单位（如 "Accuracy (%)"） |
| 正文引用 | 每张表在正文中必须被提到 |
| 加粗最优值 | 对比实验表中，最优结果加粗 |

### 公式规范

| 规范 | 说明 |
| --- | --- |
| 编号 | 右对齐，如 (1)、(2)；只对需要引用的公式编号 |
| 引用 | 正文中用「式 (1)」或 "Eq. (1)" 引用 |
| 变量说明 | 公式后面用 "where" 解释每个变量的含义 |
| 字体 | 变量用斜体，常数和函数名用正体 |

### 绘图工具推荐

| 工具 | 适合 | 特点 |
| --- | --- | --- |
| matplotlib / seaborn | 数据图（折线、柱状、散点） | Python 生态，可编程 |
| draw.io (diagrams.net) | 流程图、架构图 | 免费在线，导出矢量图 |
| TikZ (LaTeX) | 精确的学术图 | 质量最高，学习成本高 |
| Visio | 流程图、系统图 | Windows 专用 |
| Figma | UI 设计图、示意图 | 免费，协作方便 |
| Origin / MATLAB | 科学数据图 | 实验室常用 |
| plotly | 交互式图表 | 适合展示用 |

## 六、参考文献管理

### 基本原则

```
1. 每个论述都要有出处（不能凭空断言）
2. 引用格式全文统一（不要混用不同格式）
3. 参考文献列表和正文引用一一对应
4. 优先引用一手文献（原始论文），而非二手转述
5. AI 给出的参考文献必须去数据库核实
```

### 常见引用格式

| 格式 | 适用场景 | 正文引用样式 | 参考文献样式 |
| --- | --- | --- | --- |
| IEEE | 工科期刊/会议 | [1], [2] | [1] A. Author, "Title," *Journal*, vol. 1, pp. 1-10, 2024. |
| APA 7th | 社科、心理学、教育 | (Author, 2024) | Author, A. (2024). Title. *Journal*, 1(1), 1-10. |
| GB/T 7714-2015 | 中文论文 | [1] | [1] 作者. 题名[J]. 期刊, 2024, 1(1): 1-10. |
| Harvard | 部分英国期刊 | (Author 2024) | Author, A. 2024. Title. *Journal*, 1(1), pp.1-10. |

### 工具链

```
推荐工作流：
Zotero 收集文献 → Better BibTeX 导出 .bib → LaTeX/Overleaf 中 \cite{key}

Word 用户：
Zotero 收集文献 → Zotero Word 插件 → 一键插入引用 → 自动生成参考文献列表

详细操作见：03-文献检索与论文阅读/Zotero使用指南.md
```

## 七、写作效率建议

| 建议 | 说明 |
| --- | --- |
| **先写再改** | 初稿不追求完美，先把内容写出来。完美主义是写作最大的敌人 |
| **分块写作** | 不必从第一章写到最后一章，先写最熟悉的部分 |
| **设定小目标** | 「今天写完方法部分 500 字」比「今天写论文」有效得多 |
| **固定时间写** | 每天固定 2-3 小时写作时间，比零散写效率高 |
| **利用模板** | 不要从空白文档开始，找模板改 |
| **定期保存** | 用 Git 或云盘版本管理，避免丢失 |
| **及时获取反馈** | 写完一章就给导师/同学看，不要攒到最后 |
| **AI 辅助润色** | 初稿写完后用 AI 润色语言，但内容必须是自己的 |

## 八、提交前检查清单

```
内容检查：
□ 所有章节是否完整
□ 论述是否有逻辑跳跃
□ 每个论点是否有引用/数据支撑
□ 图表是否都在正文中被引用
□ 摘要是否准确反映全文内容

格式检查：
□ 标题层级是否统一
□ 字体字号是否符合要求
□ 图表编号是否连续正确
□ 参考文献格式是否统一
□ 页眉页脚是否正确
□ 页码是否正确

引用检查：
□ 正文引用和参考文献列表是否一一对应
□ 没有「幽灵引用」（列表有但正文没引用）
□ 没有「悬空引用」（正文引用了但列表没有）
□ 参考文献信息是否完整（作者、标题、期刊、年份、页码）

最终检查：
□ 字数是否符合要求
□ 文件格式是否正确（.docx / .pdf / .tex）
□ 文件名是否符合要求
□ 是否需要查重报告
□ 是否需要 AI 使用声明
```
