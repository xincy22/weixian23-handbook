## 怎么用

- 不熟悉某个工具/方向？点对应模块进去看
- 找具体内容？用 **左下角的搜索框**（也可以按 `⌘K` 或 `Ctrl+K` 唤出）
- 想问 AI 关于本站内容的问题？点右下角 **Ask AI**，第一次使用需要先填入你自己的 API Key
