## 一、综合学术搜索引擎

### Google Scholar

| 项目 | 说明 |
| --- | --- |
| 网址 | [scholar.google.com](https://scholar.google.com) |
| 覆盖 | 全学科，覆盖面最广（期刊、会议、预印本、学位论文、书籍章节） |
| 访问 | 需要科学上网；校园网下可直接获取全文链接 |
| 免费 | 完全免费 |
| 核心功能 | 关键词搜索、引用追踪（Cited by）、作者主页、Alerts 新论文通知 |
| 适合 | 第一步广泛搜索、找高引论文、追踪引用链 |

**使用要点：**
- 搜索后点「Cited by」可以看谁引用了这篇论文
- 点「Related articles」找相似论文
- 设置 → Library links → 添加你的学校 → 搜索结果会显示全文链接
- 详细检索语法见 [关键词检索方法](./keyword-search.mdx)

### Semantic Scholar

| 项目 | 说明 |
| --- | --- |
| 网址 | [semanticscholar.org](https://www.semanticscholar.org) |
| 覆盖 | 2.2 亿+ 论文，全学科 |
| 访问 | 免费，无需翻墙 |
| 核心功能 | AI 生成 TL;DR 摘要、影响力评分、引用意图分类、Research Feeds |
| 适合 | 快速评估论文重要性、发现高影响力论文、追踪研究方向 |

**独特价值：**
- **TL;DR**：每篇论文自动生成一句话总结，快速判断是否值得读
- **Influential Citations**：区分「重要引用」和「顺带提及」，帮你找到真正有影响的论文
- **Research Feeds**：关注某个话题，自动推送新论文
- **Citation Intent**：标注引用是「背景」「方法使用」还是「结果对比」

### Connected Papers

| 项目 | 说明 |
| --- | --- |
| 网址 | [connectedpapers.com](https://www.connectedpapers.com) |
| 访问 | 免费 5 张图/月，Academic $3/月或 $30/年 |
| 核心功能 | 输入一篇论文，生成相关论文的可视化图谱 |
| 适合 | 从一篇核心论文出发，发现整个研究领域的论文网络 |

**工作原理：**
- 不是引用树！基于 **共被引** 和 **文献耦合** 计算相似度
- 节点大小 = 引用次数，颜色深浅 = 发表年份
- 可以看到哪些论文是该领域的「枢纽」

**使用方法：**
```
1. 输入一篇你已经找到的核心论文的标题或 DOI
2. 生成图谱后，点击节点查看论文信息
3. 「Prior Works」标签页 → 看这篇论文的前置工作
4. 「Derivative Works」标签页 → 看后续发展
```

### ResearchRabbit

| 项目 | 说明 |
| --- | --- |
| 网址 | [researchrabbit.ai](https://www.researchrabbit.ai) |
| 访问 | 完全免费 |
| 核心功能 | 文献推荐系统，持续推送相关新论文 |
| 适合 | 长期跟踪某个方向，不错过新发表的重要论文 |

**使用方法：**
```
1. 注册账号，创建一个 Collection
2. 添加几篇你已知的核心论文
3. ResearchRabbit 自动推荐相关论文
4. 开启邮件通知，有新相关论文时提醒你
```

## 二、专业学术数据库

### Web of Science (WoS)

| 项目 | 说明 |
| --- | --- |
| 网址 | [webofscience.com](https://www.webofscience.com) |
| 覆盖 | SCI/SSCI/A&HCI 收录的高质量期刊论文 |
| 访问 | **需校园网或 VPN**（学校图书馆购买） |
| 核心功能 | 高级检索（字段代码）、引用报告、期刊影响因子、ESI 高被引 |
| 适合 | 查找高质量核心论文、分析引用趋势、确认期刊级别 |

**独特价值：**
- **Citation Report**：一组论文的引用趋势图
- **Analyze Results**：按作者/机构/国家/年份分析结果
- **ESI 高被引论文**：找到各领域 top 1% 被引论文
- 检索语法见 [关键词检索方法](./keyword-search.mdx)

## 三、预印本平台

| 平台 | 网址 | 覆盖领域 | 说明 |
| --- | --- | --- | --- |
| **arXiv** | [arxiv.org](https://arxiv.org) | AI、物理、数学、计算机、电子 | 最大预印本平台，**未经同行评审** |
| **bioRxiv** | [biorxiv.org](https://www.biorxiv.org) | 生物学 | 生物方向预印本 |
| **medRxiv** | [medrxiv.org](https://www.medrxiv.org) | 医学 | 医学方向预印本 |
| **TechRxiv** | [techrxiv.org](https://www.techrxiv.org) | 工程技术 | IEEE 旗下预印本 |

**arXiv 使用要点：**
- 分类代码：`cs.CV`（视觉）、`cs.CL`（NLP）、`cs.LG`（机器学习）、`cs.AR`（体系结构）
- 每天有 Daily Listings，可以订阅邮件
- 配合 [Papers with Code](https://paperswithcode.com) 查看论文是否有开源代码
- **注意：预印本未经同行评审，结论需谨慎对待**

## 五、全文获取方式

当你找到论文但无法下载全文时：

| 方式 | 说明 | 优先级 |
| --- | --- | --- |
| 校园网直接下载 | 学校图书馆购买了数据库权限 | ⭐⭐⭐ 首选 |
| 学校 VPN / 校外访问系统 | 在校外通过 VPN 使用图书馆资源 | ⭐⭐⭐ |
| Google Scholar 全文链接 | 设置 Library links 后，搜索结果显示 [PDF] 链接 | ⭐⭐⭐ |
| 作者主页 / ResearchGate | 很多作者会在个人主页放 PDF | ⭐⭐ |
| 预印本版本 | 在 arXiv 等平台找论文的预印本（内容可能与最终版略有差异） | ⭐⭐ |
| 图书馆文献传递 | 学校图书馆没有的文献，可申请馆际互借 | ⭐ |
| 邮件联系作者 | 礼貌地给通讯作者发邮件索取 PDF | ⭐ |

## 六、按方向推荐检索路径

| 方向 | 第一步 | 第二步 | 第三步 |
| --- | --- | --- | --- |
| 集成电路/芯片 | Google Scholar 广搜 | IEEE Xplore 精确检索 | 看 DAC/ISSCC/JSSC 会议/期刊 |
| 生物医学工程 | PubMed（免费） | IEEE Xplore + ScienceDirect | bioRxiv 追前沿 |
| 材料科学 | Google Scholar | ScienceDirect + Web of Science | Materials Project 数据库 |
| AI/机器学习 | Google Scholar + arXiv | Semantic Scholar（看影响力） | Papers with Code（找代码） |
| 精密仪器/传感器 | Google Scholar | IEEE Xplore + ScienceDirect | Web of Science 引用分析 |
| 计算机/软件 | Google Scholar + arXiv | ACM DL + IEEE Xplore | DBLP（计算机文献索引） |
