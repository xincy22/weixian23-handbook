## 一、Zotero 能帮你解决什么问题

| 问题 | Zotero 怎么解决 |
| --- | --- |
| 论文 PDF 散落在各个文件夹 | 统一管理，按项目/方向分类 |
| 忘了某篇论文的出处 | 自动保存完整题录（标题、作者、期刊、DOI） |
| 写论文时手动排参考文献 | Word/LaTeX 一键插入引用，自动生成参考文献列表 |
| 读英文论文看不懂 | 内置 PDF 阅读器 + 翻译插件划词翻译 |
| 不知道某篇论文和哪些论文相关 | 配合 Connected Papers / Semantic Scholar 使用 |

## 二、安装（3 步完成）

### 第 1 步：安装桌面端

下载地址：[zotero.org/download](https://www.zotero.org/download)

- 支持 Windows / macOS / Linux
- Zotero 7 原生支持 Apple Silicon Mac 和 Windows ARM
- 安装时会自动安装 Word 插件

### 第 2 步：安装浏览器 Connector

安装桌面端后会提示安装，或手动安装：[zotero.org/download/connectors](https://www.zotero.org/download/connectors)

- 支持 Chrome / Firefox / Edge / Safari
- Safari 版随桌面端自动安装，在 Safari 偏好设置 → 扩展中启用

### 第 3 步：注册账号（可选但推荐）

[zotero.org/user/register](https://www.zotero.org/user/register)

- 免费 300MB 云同步空间（存题录足够，PDF 建议用 WebDAV）
- 多设备同步需要账号

## 四、核心工作流

### 4.1 保存论文

**方式 A：浏览器一键保存（最常用）**

```
1. 确保 Zotero 桌面端正在运行
2. 在 Google Scholar / IEEE / ScienceDirect 等网站找到论文
3. 点击浏览器工具栏的 Zotero Connector 图标（书本/文件夹图标）
4. 论文题录 + PDF（如果有权限）自动保存到 Zotero
```

**方式 B：通过 DOI 添加**

```
1. 在 Zotero 中点击工具栏「通过标识符添加」（魔法棒图标）
2. 粘贴 DOI（如 10.1109/TPAMI.2024.xxx）
3. 回车，自动抓取完整题录
```

**方式 C：拖入 PDF**

```
1. 把 PDF 文件拖入 Zotero 主界面
2. 右键该条目 → 「从 PDF 获取元数据」
3. Zotero 自动识别论文信息（需联网，不一定准确，建议检查）
```

### 4.2 整理文献

**文件夹结构建议：**

```
我的文库
├── 课程/
│   ├── 机器学习课/
│   └── 信号与系统/
├── 科研/
│   ├── 方向A-综述/
│   ├── 方向A-方法/
│   └── 方向A-数据集/
├── 毕设/
├── 竞赛-大创/
├── 待读/
└── 已精读/
```

**标签系统：**

| 标签 | 用途 |
| --- | --- |
| `#已精读` | 认真读过并做了笔记 |
| `#待读` | 收藏了但还没读 |
| `#核心论文` | 方向内最重要的论文 |
| `#方法可复现` | 有开源代码，可以复现 |
| `#组会汇报` | 准备在组会上讲的 |

### 4.3 阅读和标注

Zotero 7 内置阅读器功能：

```
双击 PDF → 在 Zotero 内打开
- 黄色高亮：重要结论
- 红色高亮：存疑/需验证
- 蓝色高亮：方法描述
- 添加笔记：写下自己的理解
- 下划线：次要但值得注意的内容
```

标注会自动关联到文献条目，可以在笔记中引用。

### 4.4 引用和生成参考文献

**Word 用户：**

```
1. 打开 Word，找到 Zotero 工具栏（通常在「加载项」选项卡）
2. 光标放在要插入引用的位置
3. 点击「Add/Edit Citation」
4. 搜索论文标题或作者，选中，回车
5. 写完全文后，光标放在末尾
6. 点击「Add/Edit Bibliography」→ 自动生成参考文献列表
7. 切换格式：点击「Document Preferences」选择 IEEE / APA / GB/T 7714 等
```

**LaTeX 用户（需 Better BibTeX 插件）：**

```
1. 安装 Better BibTeX 插件
2. 右键文件夹 → 导出 → 选择 Better BibLaTeX 格式
3. 勾选「Keep updated」（自动同步更新）
4. 在 LaTeX 中用 \cite{citekey} 引用
5. Better BibTeX 会自动生成稳定的 citation key（如 zhang2024flexible）
```

## 五、必装插件

| 插件 | 功能 | 安装方式 | 适合谁 |
| --- | --- | --- | --- |
| **Translate for Zotero** | PDF 内划词翻译，支持 20+ 翻译服务（DeepL/Google/LLM API） | [GitHub](https://github.com/windingwind/zotero-pdf-translate/) | 所有读英文论文的同学 |
| **Better BibTeX** | 稳定的 citation key 生成，自动导出 .bib 文件 | [GitHub](https://github.com/retorquere/zotero-better-bibtex) | LaTeX 用户必装 |
| **PapersGPT for Zotero** | AI 论文总结、问答，支持 Claude/GPT/DeepSeek/Kimi 等多模型 | [GitHub](https://github.com/papersgpt/papersgpt-for-zotero) | 想用 AI 辅助读论文 |
| **Zotero GPT** | AI 对话、Command Tags 快捷操作 | [GitHub](https://github.com/MuiseDestiny/zotero-gpt) | 想用 AI 辅助读论文（备选） |
| **Better Notes** | 增强笔记功能，模板系统，知识导出 | [GitHub](https://github.com/windingwind/zotero-better-notes) | 重度笔记用户 |
| **Zotmoov** | 自动移动/重命名附件到指定目录 | [GitHub](https://github.com/wileyyugioh/zotmoov) | 想自定义 PDF 存储位置 |
| **Scite for Zotero** | 显示论文被支持/反驳/提及的引用分类 | Zotero 插件市场 | 评估论文可信度 |

### 插件安装方法

```
1. 从 GitHub Releases 页面下载 .xpi 文件
2. Zotero → 工具 → 插件 → 齿轮图标 → Install Plugin From File
3. 选择下载的 .xpi 文件
4. 重启 Zotero
```

## 六、同步方案

### 方案 A：坚果云 WebDAV（国内推荐）

```
1. 注册坚果云账号（jianguoyun.com）
2. 在坚果云中创建文件夹（如 zotero）
3. 账户信息 → 安全选项 → 添加应用 → 生成应用密码
4. Zotero → 编辑 → 设置 → 同步：
   - 数据同步：登录 Zotero 账号
   - 文件同步：选择 WebDAV
   - URL: https://dav.jianguoyun.com/dav/zotero
   - 用户名：坚果云邮箱
   - 密码：应用密码（不是登录密码）
5. 点击「Verify Server」确认成功
```

### 方案 B：Zotero 官方同步

- 免费 300MB（只够存题录和少量 PDF）
- 付费：2GB $20/年，6GB $60/年，Unlimited $120/年

### 方案 C：本地备份

```
定期备份 Zotero 数据目录：
- Windows: C:\Users\用户名\Zotero
- macOS: ~/Zotero
- Linux: ~/Zotero
```

## 八、常见问题

| 问题 | 解决 |
| --- | --- |
| Connector 点了没反应 | 确认 Zotero 桌面端是否打开（必须同时运行） |
| 保存时没有 PDF | 可能没有下载权限，手动下载后拖入对应条目 |
| 元数据不准确 | 右键 → 通过 DOI 重新获取，或手动修改 |
| Word 插件不显示 | Zotero → 编辑 → 设置 → 引用 → 文字处理器 → 重新安装 |
| 引用格式不对 | Document Preferences 中切换 Citation Style |
| 插件安装后不生效 | 确认插件兼容 Zotero 7（Zotero 6 的插件不兼容） |
| 同步冲突 | 确保同一时间只在一台设备修改，冲突时选择保留较新版本 |
