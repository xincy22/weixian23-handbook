> 现在站内**每一页底部都有评论区**，看到具体哪页有问题/想补充，直接在那页评论最方便。
> 这一页留给那些**还没归类好的**资源、链接、踩坑经验。
> 维护同学会定期把评论里的内容整理到对应板块。

---

## 怎么用

直接在本页底部的评论区发言，用 GitHub 账号登录（一次性授权）就行。

发什么都可以——一个链接 + 一句话最常见。如果想写得详细一点，参考下面的格式：

```
[资源类型] 资源名称
链接：https://...
适用方向/场景：xxx
为什么值得看：xxx
```

**发现错别字、失效链接、过期价格**：去具体那页底部评论区说更直接，也可以来 GitHub [提 Issue](https://github.com/xincy22/weixian23-handbook/issues/new) 或 PR。

---

## 维护周期

每月由维护同学整理一次，把评论里的内容迁到对应模块的正文里。整理完会在评论里 @ 提交人 "已合并到 xxx 页"。

---

## 评论的规则

- 保持友善：是同学之间的互助，不是论坛喷架
- 不发隐私：别发个人电话、学号、未公开的成绩
- 不发推广：班级共享站不是流量入口
- 被 hide 的评论不要重复发：维护者会在评论区说明 hide 原因
