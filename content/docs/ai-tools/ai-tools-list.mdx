## 四、AI 编程工具

### Claude Code vs Codex：核心区别

| 维度 | Claude Code | OpenAI Codex |
| --- | --- | --- |
| 工作哲学 | **交互式协作**：你在旁边，随时介入引导 | **异步委派**：定义任务，交出去，回来看结果 |
| 最强场景 | 复杂架构、多文件重构、遗留代码理解 | 定义明确的 ticket、并行批量任务、PR 审查 |
| SWE-bench Verified | 80.8% | 64.7% |
| Terminal-Bench 2.0 | 65.4% | 77.3% |
| Token 消耗 | 高（推理密集） | 低（约 1/3） |
| 开源 | 否 | CLI 开源，App 闭源 |
| 持久配置 | CLAUDE.md + 子 Agent + Hooks + Skills | 有限 |
| 多表面 | 终端 / VS Code / JetBrains / 桌面 / Web | CLI / 桌面 App / Web / VS Code / Cursor |

```
预算为零：
  → Copilot Free + Codex CLI/OpenCode/Aider（开源终端 Agent，用 DeepSeek API 极低成本）
  → 国内直接用：华为码道（CodeArts）免费，VS Code 插件装上即用，无需翻墙

预算 $10-20/月：
  → Copilot Pro $10（日常补全）
  → 或 Cursor Pro $20（IDE 内全搞定）
  → 或 Claude Pro $20（含 Claude Code 额度）
  → 或 ChatGPT Plus $20（含 Codex App + CLI）

最主流组合（$20-40/月）：
  → Cursor Pro（日常编码）+ Claude Code（复杂架构）或 Codex App（异步批量任务）

高级玩法：
  → Claude Code 写功能 + Codex 做 PR Review（两个 Agent 互补）
  → 社区已有 Claude Code 内调用 Codex 的 Skill

想白嫖：
  → Kiro Free + Copilot Free + Codex CLI/OpenCode（开源）+ DeepSeek 网页版
  → 纯国内方案：华为码道（CodeArts）+ 通义灵码 + DeepSeek 网页版
```

### IDE 类 vs 终端/Agent 类

| 维度 | IDE 类 (Cursor/Windsurf) | 终端 Agent (Claude Code/Codex CLI) | 异步 Agent (Codex App) |
| --- | --- | --- | --- |
| 工作方式 | 编辑器内，有 GUI | 终端内，交互式 | 派任务，后台跑 |
| 实时补全 | 有 Tab 补全 | 无 | 无 |
| 适合 | 日常编码、小修改 | 大型重构、架构工作 | 明确的 ticket、并行批量 |
| 人的参与度 | 高（实时交互） | 中（在旁边引导） | 低（定义后离开） |
| 学习曲线 | 低 | 中 | 低 |
