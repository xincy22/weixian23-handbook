## 五、写好 Prompt 的核心技巧

从上述仓库和资源中总结出的关键模式：

### 1. 角色设定（Role Prompting）

```
❌ 弱："帮我看看这篇论文"
✅ 强："You are a senior reviewer for IEEE Transactions on [领域] with 15 years of experience. Critically evaluate this paper."
```

为什么有效：激活模型在该领域的专业知识分布，回答更有深度。

### 2. 结构化输出（Structured Output）

```
❌ 弱："总结一下这篇论文"
✅ 强："Summarize using EXACTLY this structure:
## Problem (1 sentence)
## Method (2-3 sentences)  
## Key Result (specific numbers)
## Limitation (what it doesn't solve)"
```

为什么有效：防止遗漏，便于对照检查，输出可预测。

### 3. 否定约束（Negative Constraints）

```
❌ 弱："翻译这段话"
✅ 强："Translate this paragraph. Do NOT:
- Add information not in the original
- Over-translate idioms
- Change technical terms
Mark uncertain translations with [?]"
```

为什么有效：明确告诉 AI 什么不该做，减少过度发挥和幻觉。

### 4. 思维链（Chain of Thought）

```
❌ 弱："这个公式对吗？"
✅ 强："Verify this derivation step by step. For each step:
1. State what mathematical operation is applied
2. Check if it's valid (and under what conditions)
3. If there's an error, show where it first appears"
```

为什么有效：强制 AI 展示推理过程，减少跳步错误。

### 5. Few-shot 示例

```
❌ 弱："帮我写摘要"
✅ 强："Write an abstract following this example's style and structure:

[Example abstract from a paper in your field]

Now write one for my paper with these key points: ..."
```

为什么有效：给 AI 一个具体的质量标杆和格式参考。

### 6. 元提示（Meta-prompting）

当你不确定怎么写 prompt 时，让 AI 帮你写：

```
"I want to use AI to help me [描述你的任务]. 
What information should I provide, and how should I structure my prompt to get the best result?
Give me a ready-to-use prompt template."
```
