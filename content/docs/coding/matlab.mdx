## 一、什么时候用 MATLAB

适合：

- 信号处理、图像处理、控制系统、通信仿真
- 矩阵运算密集的科学计算
- Simulink 建模仿真（电路、机械、控制系统）
- 课程作业明确要求用 MATLAB 的场景

不适合：

- 通用编程、Web 开发、机器学习生产部署 → 用 Python
- 需要免费/开源 → 用 Octave 或 Python（NumPy + SciPy）
- 大数据处理、深度学习 → 用 Python（PyTorch/TensorFlow）

**经验法则：** 有的方向（信号、控制、通信）MATLAB 是事实标准，老师和论文大量用它；其他方向尽量用 Python。

## 三、最少必要知识

### 基本语法

```matlab
% 注释用 %
a = 5;              % 加分号不显示输出
b = [1 2 3; 4 5 6]; % 分号分隔行，空格分隔列
c = 1:0.1:10;       % 1 到 10，步长 0.1
d = linspace(0, 2*pi, 100);  % 0 到 2π，等分 100 点

% 矩阵运算（重点：. 表示逐元素运算）
A * B    % 矩阵乘法
A .* B   % 逐元素乘法
A ^ 2    % 矩阵平方
A .^ 2   % 逐元素平方

% 索引从 1 开始（不是 0）
b(1, 2)  % 第 1 行第 2 列
b(:, 2)  % 第 2 列所有元素
b(end, :) % 最后一行
```

### 常用函数

```matlab
% 数学
sin, cos, exp, log, sqrt, abs

% 矩阵
zeros(3, 4)   % 3x4 零矩阵
ones(3)       % 3x3 全 1 矩阵
eye(3)        % 3x3 单位矩阵
size(A)       % 矩阵维度
length(v)     % 向量长度

% 统计
mean, median, std, var, max, min, sum

% 求解线性方程 Ax = b
x = A \ b     % 反斜杠是关键，比 inv(A)*b 更快更稳定
```

### 绘图（最常用）

```matlab
x = 0:0.1:2*pi;
y = sin(x);

figure;                    % 新建图窗
plot(x, y, 'b-', 'LineWidth', 1.5);
xlabel('Time (s)');
ylabel('Amplitude');
title('Sine Wave');
grid on;
legend('sin(x)');

% 多图叠加
hold on;
plot(x, cos(x), 'r--');

% 子图
figure;
subplot(2, 1, 1); plot(x, y);
subplot(2, 1, 2); plot(x, cos(x));
```

### 函数与脚本

```matlab
% 脚本：直接保存为 .m 文件运行
% 函数：必须放在以函数名命名的 .m 文件里

function y = my_function(x, a)
    y = a * x.^2 + 1;
end

% 调用
result = my_function(1:10, 2);
```

## 四、新手最容易踩的坑

| 坑 | 解释 | 解决 |
|-----|------|------|
| 忘记 `.` 做逐元素运算 | `A^2` 是矩阵乘 `A*A`，不是逐元素平方 | 数据计算用 `.*` `./` `.^` |
| 索引从 1 开始 | 习惯了 Python/C 的会出错 | 死记硬背，IDE 会标红越界 |
| 行向量 vs 列向量 | `[1 2 3]` 和 `[1;2;3]` 不同 | 矩阵运算前先 `size(x)` 确认 |
| 直接用 `inv(A)` | 数值不稳定且慢 | 解 `Ax=b` 用 `x = A\b` |
| 循环慢 | MATLAB 解释执行循环很慢 | 尽量用矩阵向量化操作 |
| 没分号刷屏 | 大矩阵不加分号会输出几万行 | 中间步骤都加 `;` |
| 文件名和函数名不一致 | MATLAB 强制要求一致 | 函数文件以函数名命名 |

## 五、Simulink 入门要点

仅在做控制、电路、动力学仿真时用。

- **新建模型**：`File → New → Simulink Model`，或命令行 `simulink`
- **找元件**：左侧 Library Browser，搜关键词（如 "Step"、"Transfer Fcn"）
- **基本流程**：拖元件 → 连线 → 双击设参数 → 加 Scope → 运行
- **求解器选择**：连续系统用 `ode45`（默认即可），离散系统选 `Discrete`
- **常用模块**：
  - Sources：Step（阶跃）、Sine Wave、Constant
  - Sinks：Scope（示波器）、To Workspace（导出数据）
  - Continuous：Transfer Fcn（传递函数）、Integrator
  - Math：Sum、Gain、Product

## 六、和 AI 配合用 MATLAB

MATLAB 代码生成 ChatGPT/Claude 都能搞，但有几点提醒：

1. **明确说"MATLAB 代码"**：AI 默认可能给你 Python，要写明
2. **指定版本**：MATLAB R2020a 之后支持的语法（如 `arguments` 块）老版本不能用
3. **变量名习惯**：MATLAB 老代码常用 `i`、`j` 当循环变量，但 `i` 默认是虚数单位 √-1，建议用 `idx`
4. **生成绘图代码时要求专业风格**：`set(gca, 'FontSize', 12)`、`'LineWidth', 1.5` 等期刊规范
5. **复杂工具箱（如 Simulink）AI 不一定准**：涉及到 GUI 操作和 .slx 文件，AI 给的步骤可能过时，以官方文档为准

参考 [Prompt模板/全部模板](../ai-tools/prompts/all-templates) 中"代码与调试"章节的模板。

## 七、和 Python 的关系

如果你已经会 Python，MATLAB 90% 的功能都能在 Python 里做：

| MATLAB | Python 等价 |
|--------|------------|
| 矩阵运算 | NumPy |
| 信号处理 | SciPy.signal |
| 绘图 | Matplotlib |
| Simulink | scipy.integrate / SymPy / 不完全等价 |
| 控制系统工具箱 | python-control |
| 机器学习工具箱 | scikit-learn |

**建议路径：**

- 如果方向强制要用 MATLAB（如自动化、电子）：先学 MATLAB，业余时间过 Python
- 如果只是课程作业偶尔用 MATLAB：能跑就行，主力学 Python
- 长远看 Python 在工业界、科研界都更通用

## 九、文件类型速查

| 后缀 | 类型 | 说明 |
|------|------|------|
| `.m` | 脚本/函数 | MATLAB 主要代码文件 |
| `.mat` | 数据文件 | 保存变量，`save`/`load` 命令 |
| `.fig` | 图窗 | 保存可编辑的 figure |
| `.slx` | Simulink 模型 | 现代 Simulink 文件格式 |
| `.mdl` | Simulink 模型 | 老版本格式（已淘汰） |
| `.mlx` | Live Script | 类似 Jupyter Notebook，代码+文字+输出 |
