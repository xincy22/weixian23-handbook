## 一、为什么需要 Linux

很多科研代码、AI 项目、C/C++ 项目、嵌入式项目和服务器任务都运行在 Linux 环境下。原因：

- 大多数服务器和超算都是 Linux
- 很多开源项目只提供 Linux 安装说明
- EDA 工具（芯片设计）基本只跑在 Linux 上
- GPU 训练环境在 Linux 上配置更方便
- 自动化脚本和批处理在 Linux 上更自然

## 二、获取 Linux 环境的方式

| 方式 | 适合场景 | 说明 |
| --- | --- | --- |
| WSL2 (Windows) | 日常开发、学习 | Windows 内置 Linux 子系统，推荐 Ubuntu |
| 虚拟机 (VMware/VirtualBox) | 需要完整 Linux 桌面 | 性能略差，但隔离性好 |
| 双系统 | 需要原生性能 | 安装复杂，适合有经验的用户 |
| 远程服务器 (SSH) | 实验室/学校服务器 | 最常见的科研使用方式 |
| Docker | 环境复现 | 轻量级容器，适合跑别人的代码 |
| 云服务器 | 临时使用 | 阿里云/腾讯云学生优惠 |

### WSL2 安装（Windows 用户推荐）

```powershell
# 在 PowerShell（管理员）中执行：
wsl --install

# 默认安装 Ubuntu，重启后设置用户名和密码
# 之后在终端中输入 wsl 即可进入 Linux
```

## 三、必须掌握的基础命令

### 文件和目录

| 命令 | 作用 | 示例 |


## 四、SSH 远程连接

### 基本连接

```bash
ssh username@server_ip
# 输入密码后登录
```

### 密钥登录（免密码）

```bash
# 本地生成密钥对
ssh-keygen -t ed25519

# 把公钥复制到服务器
ssh-copy-id username@server_ip

# 之后连接不再需要密码
ssh username@server_ip
```

### SSH 配置文件（~/.ssh/config）

```
Host lab-server
    HostName 192.168.1.100
    User zhangsan
    Port 22
    IdentityFile ~/.ssh/id_ed25519

Host gpu-server
    HostName 10.0.0.50
    User zhangsan
    Port 2222
```

配置后可以直接：`ssh lab-server`

### 文件传输

```bash
# 上传文件到服务器
scp local_file.py username@server:/path/to/destination/

# 下载文件到本地
scp username@server:/path/to/file.py ./

# 上传整个目录
scp -r local_dir/ username@server:/path/

# rsync（增量同步，更高效）
rsync -avz local_dir/ username@server:/path/
```

## 六、gcc / g++ 编译

### 单文件编译

```bash
# C 语言
gcc main.c -o main
./main

# C++
g++ main.cpp -o main -std=c++17
./main

# 带优化
g++ main.cpp -o main -O2 -std=c++17

# 带调试信息
g++ main.cpp -o main -g -std=c++17
```

### 多文件编译

```bash
g++ main.cpp utils.cpp -o program -std=c++17
# 或分步：
g++ -c main.cpp -o main.o
g++ -c utils.cpp -o utils.o
g++ main.o utils.o -o program
```

### 链接外部库

```bash
# 链接数学库
gcc main.c -o main -lm

# 链接 OpenCV
g++ main.cpp -o main `pkg-config --cflags --libs opencv4`

# 链接 pthread
g++ main.cpp -o main -lpthread
```

## 七、CMake

CMake 是跨平台的构建系统，用于管理 C/C++ 项目的编译过程。

### 基本使用

```bash
# 项目结构
my_project/
├── CMakeLists.txt
├── src/
│   ├── main.cpp
│   └── utils.cpp
└── include/
    └── utils.h

# 构建步骤
mkdir build
cd build
cmake ..          # 生成 Makefile
make              # 编译
./my_program      # 运行
```

### 最简 CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.16)
project(MyProject)

set(CMAKE_CXX_STANDARD 17)

add_executable(my_program
    src/main.cpp
    src/utils.cpp
)

target_include_directories(my_program PRIVATE include)
```

### 链接外部库

```cmake
find_package(OpenCV REQUIRED)
target_link_libraries(my_program ${OpenCV_LIBS})
```

## 八、CUDA 基础

### 检查 GPU 和驱动

```bash
nvidia-smi                    # 查看 GPU 信息和驱动版本
nvcc --version                # 查看 CUDA 编译器版本
```

### CUDA 环境配置

```bash
# 添加到 ~/.bashrc
export PATH="/usr/local/cuda/bin:$PATH"
export LD_LIBRARY_PATH="/usr/local/cuda/lib64:$LD_LIBRARY_PATH"
```

### 常用 GPU 命令

| 命令 | 作用 |
| --- | --- |
| `nvidia-smi` | 查看 GPU 使用情况 |
| `watch -n 1 nvidia-smi` | 每秒刷新 GPU 状态 |
| `nvidia-smi -l 1` | 持续监控 |
| `CUDA_VISIBLE_DEVICES=0 python train.py` | 指定使用哪块 GPU |

## 九、tmux（终端复用）

tmux 让你在断开 SSH 后程序继续运行，也能分屏操作。

```bash
# 安装
sudo apt install tmux

# 新建会话
tmux new -s training

# 在 tmux 中运行长时间任务
python train.py

# 断开（不终止程序）：按 Ctrl+B 然后按 D

# 重新连接
tmux attach -t training

# 查看所有会话
tmux ls

# 关闭会话
tmux kill-session -t training
```

## 十、常见问题

| 问题 | 解决方法 |
| --- | --- |
| Permission denied | 检查文件权限，可能需要 `chmod +x` 或 `sudo` |
| Command not found | 检查是否安装、是否在 PATH 中 |
| 编译报错找不到头文件 | 安装对应的 `-dev` 包，如 `sudo apt install libopencv-dev` |
| 链接报错 undefined reference | 检查是否链接了对应的库（`-l` 参数） |
| CUDA out of memory | 减小 batch size，或用 `CUDA_VISIBLE_DEVICES` 选择空闲 GPU |
| SSH 连接超时 | 检查网络、防火墙、SSH 服务是否运行 |
| 磁盘空间不足 | `df -h` 查看磁盘，`du -sh *` 查看各目录大小 |
