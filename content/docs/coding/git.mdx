## 一、Git 是什么

Git 是版本管理工具，帮你：

- 记录代码的每次修改（谁改了什么、什么时候改的）
- 随时回退到之前的版本
- 多人协作时合并各自的修改
- 备份代码到远程仓库（GitHub / GitLab）

---

## 二、安装

### Windows

```
1. 下载 Git for Windows：git-scm.com
2. 安装时选择默认选项即可
3. 安装完成后打开 Git Bash 或 PowerShell
4. 验证：git --version
```

### Linux

```bash
sudo apt install git    # Ubuntu/Debian
sudo yum install git    # CentOS
```

### macOS

```bash
xcode-select --install  # 会自动安装 Git
# 或用 Homebrew：brew install git
```

### 初始配置

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

## 三、基础工作流

### 场景 1：新建项目

```bash
mkdir my-project
cd my-project
git init                    # 初始化 Git 仓库
# 写代码...
git add .                   # 把所有文件加入暂存区
git commit -m "初始提交"     # 提交
```

### 场景 2：日常开发

```bash
# 写代码、修改文件...
git status                  # 查看哪些文件被修改了
git add file1.py file2.py   # 添加要提交的文件
git commit -m "添加数据处理功能"  # 提交并写说明
```

### 场景 3：推送到 GitHub

```bash
# 先在 GitHub 上创建仓库，获取仓库地址
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main     # 第一次推送
# 之后每次：
git push                    # 推送新提交
```

### 场景 4：从 GitHub 克隆项目

```bash
git clone https://github.com/某人/某项目.git
cd 某项目
# 现在你有了项目的完整代码和历史
```

## 四、常用命令速查

| 命令 | 作用 |
| --- | --- |
| `git init` | 初始化仓库 |
| `git clone <url>` | 克隆远程仓库 |
| `git status` | 查看当前状态 |
| `git add <file>` | 添加文件到暂存区 |
| `git add .` | 添加所有修改 |
| `git commit -m "说明"` | 提交 |
| `git log --oneline` | 查看提交历史（简洁版） |
| `git diff` | 查看未暂存的修改 |
| `git push` | 推送到远程 |
| `git pull` | 拉取远程更新 |
| `git branch` | 查看分支 |
| `git checkout -b <name>` | 创建并切换分支 |
| `git merge <branch>` | 合并分支 |
| `git stash` | 临时保存未提交的修改 |
| `git stash pop` | 恢复临时保存的修改 |

## 五、.gitignore 文件

告诉 Git 哪些文件不需要跟踪：

```text
# Python
__pycache__/
*.pyc
.venv/
*.egg-info/

# Jupyter
.ipynb_checkpoints/

# 数据文件（太大不适合放 Git）
data/
*.csv
*.h5

# 环境和配置
.env
*.log

# IDE
.vscode/
.idea/

# 系统文件
.DS_Store
Thumbs.db
```

## 六、提交信息怎么写

好的提交信息让你以后能快速找到某次修改。

### 格式建议

```
<类型>: <简短描述>

类型：
- feat: 新功能
- fix: 修复 bug
- docs: 文档修改
- refactor: 重构（不改功能）
- test: 添加测试
- chore: 杂项（配置、依赖等）
```

### 示例

```
feat: 添加数据预处理模块
fix: 修复 CSV 读取时编码错误
docs: 更新 README 安装说明
refactor: 将数据加载逻辑抽取为独立函数
```

## 七、GitHub 使用建议

| 功能 | 用途 |
| --- | --- |
| Repository | 存放项目代码 |
| README.md | 项目说明（别人打开仓库第一眼看到的） |
| Issues | 记录 bug 和待办事项 |
| Pull Request | 代码审查和合并 |
| Actions | 自动化测试和部署 |
| Pages | 免费托管静态网站 |

### 注意事项

```
1. 不要把 API Key、密码、token 提交到 GitHub
2. 不要把大文件（>100MB）提交到 Git（用 .gitignore 排除）
3. 公开仓库所有人都能看到，注意不要放敏感信息
4. 写好 README，让别人（和未来的自己）能看懂项目
```

## 八、常见问题

| 问题 | 解决方法 |
| --- | --- |
| push 被拒绝 | 先 `git pull` 拉取远程更新，解决冲突后再 push |
| 提交了不该提交的文件 | `git rm --cached <file>` 然后加入 .gitignore |
| 想撤销最近的修改 | `git checkout -- <file>`（未暂存）或 `git reset HEAD <file>`（已暂存） |
| 想回到之前的版本 | `git log` 找到 commit ID，`git checkout <id>` 查看 |
| 合并冲突 | 打开冲突文件，手动选择保留哪部分，然后 add + commit |
| clone 速度慢 | 配置 Git 代理或使用镜像 |

## 九、VS Code 中使用 Git

VS Code 内置了 Git 支持：

1. 左侧栏「源代码管理」图标可以看到所有修改
2. 点击文件旁的 `+` 号相当于 `git add`
3. 在消息框输入提交信息，点击 ✓ 相当于 `git commit`
4. 底部状态栏可以看到当前分支
5. 安装 GitLens 扩展可以看到每行代码的修改历史
