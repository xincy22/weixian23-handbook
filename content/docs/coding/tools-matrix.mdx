## 按用途选择工具

| 你想做什么 | 推荐工具 | 说明 |
| --- | --- | --- |
| 数据处理和分析 | Python (pandas, numpy) | 最通用的数据处理方案 |
| 交互式数据探索 | Jupyter Notebook / JupyterLab | 边写代码边看结果，适合实验和课程 |
| 数值计算和仿真 | MATLAB | 矩阵运算、信号处理、控制系统 |
| 实验数据绘图 | Origin / matplotlib | Origin 适合快速出图，matplotlib 适合自定义 |
| 论文级图表 | matplotlib / pgfplots (LaTeX) | 可精确控制每个细节 |
| 写代码 | VS Code | 最通用的编辑器，插件生态丰富 |
| AI 辅助写代码 | Cursor / Claude Code / GitHub Copilot | 集成 AI 的编程环境（详见 02-AI工具与API/AI工具大全.md） |
| 版本管理 | Git + GitHub | 代码备份、协作、版本追踪 |
| 服务器操作 | SSH + Linux 命令行 | 远程连接服务器跑实验 |
| C/C++ 项目构建 | CMake + gcc/g++ | 跨平台构建系统 |
| 深度学习 | PyTorch | 科研首选框架（2026 年市场份额 >80%） |
| GPU 加速 | CUDA + cuDNN | 深度学习和并行计算 |
| 环境隔离 | conda / uv / Docker | 避免不同项目的依赖冲突 |
| Python 包管理 | uv（新）/ pip + venv（传统） | uv 比 pip 快 10-100 倍 |
| 文档和笔记 | Markdown + VS Code / Obsidian | 轻量、可版本管理 |
| 电路仿真 | Cadence / HSPICE / LTspice | 模拟电路设计和验证 |
| 数字电路 | Vivado / Quartus | FPGA 开发 |
| 芯片验证 | VCS + Verdi / ModelSim | SystemVerilog / UVM |
| 有限元分析 | COMSOL / ANSYS / Abaqus | 结构、热、电磁仿真 |
| PCB 设计 | Altium Designer / KiCad | 电路板设计（KiCad 免费开源） |
| 3D 建模 | SolidWorks / Fusion 360 | 机械结构设计 |
