## 一、注册

1. 打开 [github.com](https://github.com)，点 Sign up
2. 填邮箱、密码、用户名（建议用真名拼音或者好记的 ID，以后简历上会放）
3. 验证邮箱

注册完之后建议立刻做两件事：

- **头像换掉**（默认的像素方块不好辨认）
- **Bio 写一行**（比如"THU EE 2022 / ML & Signal Processing"），方便别人知道你是谁

## 二、SSH 连接 GitHub（免密 push/pull）

用 HTTPS clone 仓库每次 push 都要输密码（或者配 credential helper）。**用 SSH 一劳永逸**。

### 2.1 生成密钥

如果你在 [远程开发工作流](./remote-dev.mdx) 那篇里已经生成过 `~/.ssh/id_ed25519`，直接用同一把就行，不用再生成。

没有的话：

```bash
ssh-keygen -t ed25519 -C "your-email@example.com"
# 一路回车
```

### 2.2 把公钥添加到 GitHub

```bash
# 复制公钥内容
cat ~/.ssh/id_ed25519.pub
# 输出类似：ssh-ed25519 AAAAC3Nz... your-email@example.com
```

然后：

1. 打开 [github.com/settings/keys](https://github.com/settings/keys)
2. 点 **New SSH key**
3. Title 随便写（比如"我的笔记本"）
4. Key type 选 **Authentication Key**
5. 把刚才复制的公钥粘贴进去
6. 点 **Add SSH key**

### 2.3 测试连接

```bash
ssh -T git@github.com
```

看到 `Hi your-username! You've been authenticated...` 就成功了。

### 2.4 之后 clone 用 SSH 地址

```bash
# SSH 地址（推荐）
git clone git@github.com:username/repo.git

# 不是 HTTPS 地址
# git clone https://github.com/username/repo.git
```

已有仓库从 HTTPS 切到 SSH：

```bash
git remote set-url origin git@github.com:username/repo.git
```

## 三、创建仓库

### 在 GitHub 网页上创建

1. 右上角 `+` → **New repository**
2. 填仓库名（建议用英文 kebab-case，如 `my-project`）
3. 选 Public 或 Private
4. 勾选 **Add a README file**（这样仓库不是空的，clone 下来就能用）
5. 选一个 `.gitignore` 模板（比如 Python）
6. 选 License（开源项目选 MIT 最简单）
7. 点 **Create repository**

### 把本地已有项目推上去

```bash
cd my-project
git init
git add .
git commit -m "init"

# 在 GitHub 上创建一个空仓库（不要勾 README），拿到 SSH 地址
git remote add origin git@github.com:username/my-project.git
git branch -M main
git push -u origin main
```

## 四、Fork + Pull Request（给别人项目贡献）

这是 GitHub 上最核心的协作模式。流程：

```
1. Fork：把别人的仓库复制一份到你自己的账号下
2. Clone：把你 fork 的仓库 clone 到本地
3. Branch：新建一个分支做修改
4. Commit + Push：改完推到你自己的 fork
5. Pull Request：在 GitHub 上发起 PR，请求原仓库合并你的改动
6. Review：原仓库维护者审查、讨论、要求修改
7. Merge：维护者合并你的 PR
```

### 具体操作

```bash
# 1. 在 GitHub 网页上点 Fork 按钮

# 2. Clone 你 fork 的仓库
git clone git@github.com:你的用户名/仓库名.git
cd 仓库名

# 3. 新建分支
git checkout -b fix-typo

# 4. 做修改、提交
git add .
git commit -m "fix: 修正第三章的公式错误"

# 5. 推到你的 fork
git push origin fix-typo

# 6. 打开 GitHub，会看到一个黄色横幅提示你 "Compare & pull request"
#    点进去，填写 PR 标题和描述，点 Create pull request
```

### PR 写什么

- **标题**：一句话说清楚改了什么（`fix: 修正第三章公式错误`）
- **描述**：为什么改、改了哪里、怎么验证。如果是修 bug 可以贴截图

### 同步上游更新

你 fork 之后原仓库可能继续更新。保持同步：

```bash
# 添加上游仓库为 remote
git remote add upstream git@github.com:原作者/仓库名.git

# 拉取上游更新
git fetch upstream
git checkout main
git merge upstream/main

# 推到你的 fork
git push origin main
```

## 五、Issues：记录问题和想法

Issues 是 GitHub 内置的"任务/bug 追踪系统"。

### 什么时候开 Issue

- 发现了 bug
- 想提一个功能建议
- 有问题想问维护者
- 记录自己的 TODO（私有仓库里）

### 怎么写一个好 Issue

```markdown
## 问题描述
（简短说明出了什么问题）

## 复现步骤
1. ...
2. ...
3. ...

## 期望行为
（应该是什么样的）

## 实际行为
（实际是什么样的）

## 环境
- OS: macOS 15 / Ubuntu 22.04
- Python: 3.11
- 相关版本号
```

## 六、GitHub Pages：免费托管静态网站

GitHub 可以把仓库里的 HTML/Markdown 直接变成一个网站。适合：

- 个人主页 / 简历
- 项目文档
- 课程笔记

### 开启方法

1. 仓库 → **Settings** → 左侧 **Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 `main`，文件夹选 `/ (root)` 或 `/docs`
4. 点 Save

几分钟后网站就上线了，地址是 `https://你的用户名.github.io/仓库名/`。

如果仓库名是 `你的用户名.github.io`，那网站地址就是 `https://你的用户名.github.io/`（个人主页）。

## 八、实验室 / 课题组怎么用 GitHub 协作

### 方案 A：共享仓库（小组 3-5 人）

所有人都是仓库的 Collaborator，直接 push 到同一个仓库的不同分支：

```bash
git checkout -b feature/my-part
# 做修改...
git push origin feature/my-part
# 在 GitHub 上发 PR 合并到 main
```

添加 Collaborator：仓库 → Settings → Collaborators → 输入对方用户名。

### 方案 B：Organization（实验室级别）

创建一个 Organization（免费），把实验室所有人加进去。好处：

- 仓库归组织所有，不怕某个人毕业后删号
- 可以建多个仓库（每个项目一个）
- 可以设 Team 权限（比如"只读"和"可写"分开）

创建：[github.com/organizations/new](https://github.com/organizations/new)

## 九、几个实用技巧

| 技巧 | 怎么做 |
|---|---|
| 快速搜索仓库内容 | 在仓库页面按 `t` 键，可以模糊搜索文件名 |
| 看某行代码的历史 | 点行号 → 右键 → View git blame |
| 引用某行代码给别人看 | 点行号，URL 会变成 `#L42`，复制发给别人 |
| 快速编辑文件 | 在仓库页面按 `.` 键，打开网页版 VS Code |
| 下载单个文件 | 点文件 → Raw → 右键另存为 |
| 看 trending 项目 | [github.com/trending](https://github.com/trending) |
| 搜索开源项目 | 搜索框 + 筛选 language / stars / license |

## 十、常见问题

| 问题 | 解决 |
|---|---|
| push 报 `Permission denied (publickey)` | SSH key 没配好，回第二节重新来 |
| push 报 `remote: Repository not found` | 仓库地址写错了，或者你没有权限（私有仓库没被加为 Collaborator） |
| 想删掉某次提交里的敏感信息 | 用 [BFG Repo-Cleaner](https://rtyley.github.io/bfg-repo-cleaner/) 或 `git filter-branch`。注意：已经 push 的历史别人可能已经 clone 了 |
| 仓库太大 clone 很慢 | `git clone --depth 1 <url>`（浅克隆，只拉最新一次提交） |
| 想把私有仓库变公开 | Settings → Danger Zone → Change visibility。**想清楚再点** |
| 学生认证一直不通过 | 用学校邮箱（edu.cn）注册 GitHub 账号，或者上传学信网在读证明截图 |
